# AddCalender
Ứng dụng giúp bạn **thêm sự kiện vào lịch** nhanh chóng, đơn giản và không rườm rà.

![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-active-brightgreen)

## ✨ Tính năng

- ➕ Thêm sự kiện mới chỉ với vài thao tác (tiêu đề, ngày, giờ, ghi chú)
- ✏️ Sửa và xóa sự kiện
- 🔔 Nhắc lịch trước giờ diễn ra [nếu có]
- 📆 Xem lịch theo ngày / tuần / tháng [nếu có]
- 💾 Lưu dữ liệu [cục bộ / trên cloud]

```bash
# 1. Clone dự án
git clone https://github.com/artemisha/AddCalender.git
cd https://github.com/artemisha12/AddCalender

# 2. Cài đặt thư viện
[npm install / pip install -r requirements.txt / make]

# 3. Chạy ứng dụng
[npm start / python main.py / ./app]
```

## 📖 Cách sử dụng

1. Mở ứng dụng.
2. Bấm **Thêm sự kiện**.
3. Nhập tiêu đề, ngày, giờ rồi bấm **Lưu**.
4. Sự kiện sẽ xuất hiện trên lịch của bạn.
